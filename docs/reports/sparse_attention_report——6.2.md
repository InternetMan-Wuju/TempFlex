## 关键观察

1. **Manual attention 在大多数场景占优**: 在 1 种稀疏模式 × 8 种 shape = 8 个测试组合中，manual attention 走 NPU 高度优化的矩阵乘法通路。

2. **Flex Attention 在所有场景中未反超**: 没有出现 Flex 比 Manual 快的情况。

3. **Flex Attention 在不同稀疏模式下的时间表现**: 不同稀疏 mask 的计算复杂度不同，对 Flex Attention 和 Manual Attention 的影响程度也不同。只当 score_mod 为 identity 且 mask_mod 为纯 causal 时，flex attention 能命中内联优化路径。

4. **所有测试的 allclose 检查均通过**: 所有组合的 max_rel_diff 均在 3% 以内，fail_ratio 为 0%。说明 flex attention 的数值精度与 manual attention 一致。

5. **结论**: 在这一 NPU 平台上，对于序列长度 ≤2048、head_dim ≤128 的场景，manual attention 是多数场景的更优选择。Flex Attention 的优势在于内存效率和长序列扩展能力，而非小 shape 的绝对速度。
